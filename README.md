# 🤖 Wikipedia Telegram Bot

A smart, fast, and efficient Telegram bot built with Python that allows users to search for and read Wikipedia articles directly inside Telegram without leaving the app.

---

### 🚀 Features
- 🔍 **Instant Search:** Search for any topic on Wikipedia in seconds.
- 🌐 **Multilingual Support:** Fetch Wikipedia articles based on user language preferences.
- ⚡ **Lightweight & Fast:** Optimized codebase for quick response times.

### 🛠️ Tech Stack
- **Language:** Python 3.x
- **Framework:** Aiogram / Telebot (Telegram Bot API)
- **API:** Wikipedia AP

**pip install wikipedia**
**pip install aiogram**
